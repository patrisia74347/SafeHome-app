🏠 SafeHome - Seiful tău de Garanții
SafeHome este o aplicație web Full-Stack concepută pentru a ajuta utilizatorii să își gestioneze și să urmărească garanțiile produselor electronice și electrocasnice într-un mod simplu și eficient.

🚀 Funcționalități Cheie
Autentificare Securizată: Sistem de conturi (Înregistrare/Login) cu parole criptate prin Bcrypt.

Managementul Produselor: Adăugarea, editarea și ștergerea produselor din inventar.

Monitorizarea Garanției: Calcularea automată a zilelor rămase și afișarea unei bare de progres vizuale (Verde/Galben/Roșu).

Căutare Rapidă: Filtrarea produselor în timp real după nume sau model.

Notificări E-mail: Trimiterea unui e-mail de bun venit la crearea contului (via Flask-Mail).

🛠️ Tehnologii Folosite
Frontend: HTML5, CSS3 (Bootstrap 5), JavaScript (Vanilla).

Backend: Python 3.10, Flask.

Bază de date: SQLite cu SQLAlchemy (ORM).

Securitate: Flask-Bcrypt pentru hashing-ul parolelor.

Server: Găzduit pe PythonAnywhere.
